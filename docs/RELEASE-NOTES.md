# 源码更新记录

## 2026-09-09 · 淡桃粉 UI 源码预览版

首页、喝奶、历史、设置、大便、小便和睡眠七页采用新的淡桃粉界面，并统一其他事项、宝宝资料、导出、备份恢复及异常状态的控件。首页保留幸福手写文案和宝宝插画，摘要、时间线及快捷记录共用竖直奶瓶与方底图标；浅色、深色和跟随系统均可用。

- 首页“奶量”合计奶粉与瓶喂母乳的毫升数，亲喂时长不换算为毫升。进行中睡眠单独显示，“醒了”仍需确认。
- 表单统一日期时间、滚动、键盘避让与底部安全区；小屏和大字下关键内容重排，保存入口可滚动访问。
- 修复 Android 页面返回与切后台时普通文字选择引发的原生崩溃；普通展示文字不再长按复制，输入框仍支持手动编辑和选择。
- 修复 Android 奶量框自动全选覆盖第一位数字的问题，避免输入120变成20；保留手动修改和加减操作。
- 12张透明运行素材、独立素材检查与七页浅深色虚构示例截图一并提供。来源见 [UI 素材说明](UI-ASSETS.md)，效果见 [截图索引](screenshots/soft-rose/README.md)。

业务合同保持为 SQLite `user_version=9`、完整备份2写/1与2读、CSV33列及四种喂养方式。此UI更新没有新增迁移，不改变照片管理、睡眠归属或本地提醒规则。

实现经过API 36模拟器走查。公开文件在干净目录重新执行 `npm ci` 后，97组573项测试、schema9、类型、lint、两套素材检查、Expo公开配置和Android export全部通过；65个打包素材包含全部12张UI PNG。

本次发布是源码快照，应用配置保持 Android `1.0.1` / `versionCode=4`；不提供APK/AAB，也不表示完成新的签名构建、真机覆盖升级或商店发布。iOS、Web、完整TalkBack和中文IME流程尚未完成产品验收。
